What am I looking at?

This is an open-source, runs-anywhere mock of the Global Workspace / Jacobian-lens interpretability interface. The Jacobian lens reads out which vocabulary tokens a model is “poised to verbalise” at each layer and token position — a proxy for the model's internal, reportable workspace.

  • Sensory layers (early) echo the input token and its sub-pieces.
  • Workspace layers (middle) surface semantically related concepts — this is where “verbalizable thought” lives, and where activity peaks.
  • Motor layers (late) collapse onto the likely next token.

The default mock backend is fully synthetic and needs no ML libraries, so the UI runs anywhere. Start the server with --model gpt2 (with torch + transformers installed) to drive the same views with a real open-source model via a logit-lens approximation of the J-lens.

Inspired by Transformer Circuits: Verbalizable Representations & the Global Workspace and Neuronpedia. Readouts here are illustrative, not real model internals.
